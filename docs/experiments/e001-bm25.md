# E001: BM25 Baseline

## Question

How well does lexical retrieval perform across the benchmark's query classes?

## Hypothesis

BM25 will perform strongly on queries containing exact people, project, topic, status, and
attachment terms, but it will be vulnerable to paraphrases and implicit intent.

## Configuration

Use `experiments/configs/001_bm25.yaml`.

## Required analysis

- aggregate metrics;
- scenario-level metrics;
- p50/p95 latency;
- worst 20 NDCG@10 queries;
- error labels such as vocabulary mismatch, ambiguity, recency, and multi-constraint failure.

## Decision use

E001 establishes the control for E002 and E003. It should not be tuned after viewing treatment
results without versioning a new baseline.
