# Glossary

- **Candidate retrieval:** Fast first-stage process that aims to find a broad relevant set.
- **Dense retrieval:** Retrieval using vector representations and similarity.
- **DCG:** Discounted Cumulative Gain, a graded ranking-quality metric.
- **Hybrid retrieval:** Combination of two or more retrieval methods.
- **MRR:** Mean Reciprocal Rank, focused on the rank of the first relevant result.
- **NDCG:** Normalized DCG, enabling graded ranking comparison across queries.
- **Precision:** Fraction of retrieved documents that are relevant.
- **Recall:** Fraction of known relevant documents that were retrieved.
- **Reranking:** More expensive scoring applied to a bounded candidate set.
- **RRF:** Reciprocal Rank Fusion, a rank-based method for combining retrieval lists.
- **Scenario slice:** Metrics calculated for one query category.
- **Synthetic corpus:** Artificial data generated to provide safe, controlled evidence.
