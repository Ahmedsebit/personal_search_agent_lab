# Benchmark v2

The default benchmark contains 2,000 synthetic emails and 200 queries. It adds ambiguous full names, near-neighbor project names, aliases, semantic paraphrases, misspellings, hard negatives, explicit difficulty labels, structured intent, and recency-aware graded relevance. The audit validates identifiers, grades, positive coverage, and scenario/difficulty distributions.

This remains a synthetic engineering benchmark, not evidence of organic enterprise-search quality. Later work should add independently authored queries and blinded review over safe data.
